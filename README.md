# Agentic AI Projects

A collection of Agentic AI projects developed as part of the Agentic AI
course at the University of Layyah Short Course Program (ULSCP).

## Projects

### Project 01 --- Intelligent Task Execution Agent

An agent that receives a goal, breaks it into smaller tasks, selects
appropriate tools, executes the workflow, and returns a useful result.

**Main Concepts:** ReAct, Tool Calling, LangChain

### Project 02 --- Knowledge-Based Decision Agent

An agent that retrieves information from a knowledge base and uses the
retrieved context to answer questions, provide recommendations, or
support decisions.

**Main Concepts:** Agentic RAG, Chroma, LangGraph

### Project 03 --- Multi-Agent Problem Solving System

A multi-agent system in which specialized agents collaborate on a
complex task, with a workflow responsible for coordinating the process.

**Main Concepts:** Multi-Agent Workflows, LangGraph, Tool Calling

### Project 04 --- AI Document Analyzer

An AI-powered document processing application that allows a user to
upload a document, extract relevant information, analyze its content,
and produce structured results.

**Main Concepts:** RAG, Pydantic, Chroma

### Project 05 --- Intelligent Communication Assistant

An agent that analyzes information and prepares appropriate
communications or notifications according to defined conditions.

**Main Concepts:** Email Automation, Notifications, Tool Calling

### Project 06 --- Telegram Agentic AI Assistant

A Telegram-based Agentic AI assistant that receives user queries,
processes them through an agentic workflow, uses tools when required,
and returns an appropriate response.

**Main Concepts:** Telegram Bot, LangGraph, Agent + Tools

### Project 07 --- TripWise AI

**AI-Powered Travel Planning System**

TripWise AI is the main independent Agentic AI project. It creates a
personalized travel plan from the user's travel requirements by
combining multiple AI agents with real-world APIs.

The workflow includes: - Planner Agent - Research Agent - Budget Agent -
Itinerary Agent - Validator Agent

The system can provide destination information, weather information,
nearby places, budget breakdowns, and a personalized day-by-day
itinerary.

**Technologies:** Python, Streamlit, LangGraph, LangChain, ChatGroq,
Groq AI, Pydantic, Open-Meteo API, OpenStreetMap/Overpass API, Requests
