University Agentic AI Course Information

The Agentic AI course requires students to build practical
production-oriented Agentic AI applications.

Students should use Python and may use technologies such as
LangChain, LangGraph, n8n, Streamlit, Chroma and different LLM providers.

Project 1 is an Intelligent Task Execution Agent.
It receives a goal, breaks it into smaller tasks, selects appropriate
tools, executes the workflow and returns a useful result.

Project 2 is a Knowledge-Based Decision Agent.
It retrieves information from a private knowledge base and uses the
retrieved context to answer questions, make recommendations or support decisions.

Project 2 demonstrates Agentic RAG, Chroma and LangGraph.

Every project should have a functional Streamlit user interface.

Projects should include meaningful error handling and validation.

API keys, passwords, tokens and other private credentials must not
be uploaded to GitHub.

Each project should have clear documentation and a README with
setup instructions, architecture, technologies and usage examples.

Students should understand their own code because the instructor
may ask them to demonstrate or explain their submitted project.
